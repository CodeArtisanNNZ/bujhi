# Bujhi — Home and About frontend

This package contains the clean first stage of Bujhi's frontend:

- `/` — interactive homepage with a notebook-style learning preview, animated solar system, hidden quiz and touchable learning prompts.
- `/about` — founder story, Millennium Fellowship context and a three-image interactive story gallery.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Deploy with GitHub and Vercel

1. Upload every file and folder in this project to the root of your GitHub repository.
2. Import the repository in Vercel.
3. Keep the framework preset as **Next.js**.
4. Deploy. No environment variables are required.

Login, registration, classroom perspectives and dashboards are intentionally reserved for the next frontend stages.
