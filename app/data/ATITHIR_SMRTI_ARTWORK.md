# Atithir Smriti illustration repair

The previous binary sprite and its base64 text chunks were damaged. They are replaced by ten complete, separately served WebP images. The image bytes must be uploaded as base64 Git blobs and verified against local Git blob hashes.

The original textbook story passages remain unchanged. Scene headings, illustrations, and memory notes are Bujhi reading support.

## Artwork

Created with the built-in image generation tool. Style reference: the user’s saved vintage Bengali woodcut image `image-gen-4(20261021-234725).png`.

Shared brief: landscape 4:3 vintage Bengali woodcut / linocut; black carved lines, terracotta red, muted ochre, aged cream paper; early twentieth-century Deoghar; a middle-aged to older Bengali narrator in a white dhoti and simple kurta, and an ageing tan Indian street dog; no text, watermarks, modern objects, grids or collages.
